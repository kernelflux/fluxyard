# Fluxyard v0.1 Foundation Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship a clone-and-run local Agent Control Plane that registers workspaces, runtime nodes and agents, records immutable usage events, and reports attributed usage through a CLI.

**Architecture:** Fluxyard v0.1 is a TypeScript modular monolith with dependency direction `cli -> json-store -> core`. The core owns runtime-neutral enterprise facts and invariants; adapters will translate DeepSeek Harness and future runtimes in later versions. A JSON store gives the first release durable local behavior without committing the product to its future SQLite/PostgreSQL implementations.

**Tech Stack:** Node.js 22+, TypeScript 6, Node test runner, pnpm, GitHub Actions.
